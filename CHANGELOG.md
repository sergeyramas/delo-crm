# CHANGELOG

## 0.2.1 — 2026-11-12

- Подписант, отправитель и реквизиты — защищённые подстановки, не редактируются. Решение Сергея 12.11: подпись Андрея, как на бою. `{подписант}` — блок подписи из файла по пути в `CRM_MAIL_SIGNATURE_FILE` (умолчание пусто, в коде нет ни текста подписи, ни телефонов), `{отправитель}` — имя From «Перевозчик 21»:
  ключи `mail.from_name` и `mail.client.signature` убраны из каталога, страницы,
  API и snapshot. В текстах — только подстановки `{подписант}`, `{отправитель}`,
  `{реквизиты}`; для `mail.client.body` и `*.template_md` без `{подписант}` сохранение
  отклоняется (`missing_signer`).
- Проверка текстов: ссылки, e-mail, ИНН/р/с/БИК-подобные цифры запрещены.
  Отказы API отдают `{"code","message"}`; текст не цитирует запрещённое.
- Рендер подстановок — только по белому списку, без `str.format` и Jinja.
- `POST|PATCH /s/settings/{key}` для правки/публикации с тем же секретом шлюза.

## 0.2.0 — 2026-11-12

- Страница «Настройки» (этап 1): тексты писем, заявки перевозчику, постов в группе,
  подписей кнопок, стадий и заголовка нюансов.
- Каталог ключей с умолчаниями из Дела, проверка подстановок и запретов, черновики,
  публикация, история версий, откат и сброс к умолчанию.
- `GET /s/settings/snapshot` для воркера: только опубликованные значения, общий `version`.
- Версия показывается в `/health`.
