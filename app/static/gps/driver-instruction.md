# Инструкция водителю: приложение «АТИ Водитель»

**Зачем:** чтобы диспетчер видел, где машина во время рейса, без лишних звонков.  
**Приложение:** бесплатное, только Android.  
**Важно:** ставь именно «АТИ Водитель» (GPS). Не путай с «АТИ Грузы и Транспорт» — то другое приложение, для поиска грузов.

## 1. Установка

Нужен телефон на **Android**.

1. Открой одну из ссылок (что удобнее):
   - **Google Play:** https://play.google.com/store/apps/details?id=su.ati.driver  
     Название в магазине: **«АТИ Водитель GPS»** (пакет `su.ati.driver`).
   - **RuStore:** https://www.rustore.ru/catalog/app/su.ati.driver  
     Название: **«АТИ Водитель»**.
2. Нажми **Установить** → дождись установки → открой приложение.
3. Если ссылка не открывается — в поиске магазина набери **«АТИ Водитель»** и проверь, что пакет `su.ati.driver` / издатель ATI.SU.

QR-код и те же ссылки есть на странице ATI: https://ati.su/landings/ati-driver/

---

## 2. Регистрация и вход

1. Зарегистрируйся **по номеру телефона**.
2. Номер должен быть **тем же**, который диспетчер указал в справочнике водителей на ATI.SU.
3. Подтверди вход кодом из SMS (как попросит приложение).

Если номер другой — приложение не свяжется с заказами нашей фирмы. Напиши диспетчеру.

---

## 3. Принять заказ

Заказы в «АТИ Водитель» приходят **только с сайта ATI.SU** — их отправляет диспетчер.

1. Когда придёт заказ — открой его и посмотри маршрут, даты, контакты на точках.
2. Если подходит — нажми **«Взять заказ»**.
3. Если не подходит — откажись и укажи причину. Диспетчер получит уведомление.

В настройках приложения включи **«Автоматическое отслеживание заказов»**. Тогда после «Взять заказ» передача координат начнётся сама — первый статус руками ставить не нужно.

В заказе можно:
- открыть **«Навигатор»** — координаты точек подставятся сами;
- написать диспетчеру в чат (**«Написать»**);
- приложить фото/документы (**«Добавить документы»**).

## 4. Геолокация «всегда» и батарея

Без геолокации трек не пишется. По подсказкам ATI:

1. Разреши приложению доступ к геопозиции **на время перевозки**.
2. Выбери режим **«Всегда» / «В любом режиме»** (фоновый доступ) — чтобы при свёрнутом приложении маршрут не терялся.
3. **Не выключай** GPS и геолокацию, пока заказ в работе.
4. Не включай экономию батареи так, чтобы система «усыпляла» «АТИ Водитель».

### Общий Android

- **Настройки → Приложения → АТИ Водитель → Батарея** → режим **Без ограничений** / «Не оптимизировать».
- **Настройки → Местоположение** → включено; для приложения — **Всегда**.
- Уведомления для «АТИ Водитель» — **включены** (чтобы видеть заказ и напоминания о статусах).

### Xiaomi / Redmi / POCO (MIUI / HyperOS)

- Автозапуск: **разрешить** для «АТИ Водитель».
- Экономия батареи → приложение → **Нет ограничений**.
- «Защита приложений» / блокировка в недавних — закрепи приложение, чтобы система его не убивала.

### Samsung

- **Настройки → Батарея → Ограничение использования в фоне** — исключи «АТИ Водитель».
- «Неконтролируемая активность» / «Разрешить работу в фоне» — **вкл**.

### Huawei / Honor (EMUI / Harmony)

- Запуск вручную / автозапуск — **разрешить**.
- Зависимости / «Работа в фоне» — **вкл**.
- Батарея → запуск приложений → «АТИ Водитель» → вручную все тумблеры **вкл**.

Если пропала сеть на трассе — не страшно: при включённых телефоне и GPS приложение может копить статусы **до 4 дней**, потом отправит, когда появится связь.

## 5. Статусы рейса — что нажимать

Статусы меняешь **ты** в приложении. Диспетчер видит каждое изменение. Приложение само напомнит, если долго не обновлял статус.

По публичной справке ATI возможные статусы:

| Когда | Что сделать |
|---|---|
| Заказ пришёл | **«Взять заказ»** или отказаться с причиной |
| Начал работу | Поставь статус начала (в справке для водителя: **«Еду на загрузку»**; в общем списке ATI также: начал выполнять / **на загрузке**) |
| Приехал на склад погрузки | **на загрузке** |
| Машина загружена, едешь | **загрузился** |
| Приехал на выгрузку | **на разгрузке** |
| Выгрузился | **разгрузился** |
| Рейс закончен | **заверши заказ** — после этого отслеживание останавливается |

Если GPS или телефон выключены — у диспетчера это тоже видно. Не выключай.

Чат с диспетчером: в заказе кнопка **«Написать»** (АТИ Мессенджер).

## 7. Кто видит координаты

- Координаты видят **только руководители и диспетчер этого рейса**.
- Хранение у нас: **30 дней**.
- Передача идёт **только пока заказ в работе**. После завершения заказа отслеживание по этому рейсу останавливается.
- Мы не смотрим другие приложения на телефоне.
